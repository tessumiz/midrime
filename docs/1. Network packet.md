cls ConnMgr:
    @state En [ Connecting, Connected, Disconnected*, Fault ]

    lst_attr = 0
    ret = 0
    q = []

    init(max_ret): ...  // @fill by default

    ingest(packs):
        use bad = $['bad']  // aliases AST node rather than a text macro

        q << packs
            => sel !bad
            => map  bad.trim().upr()
            => dec  bad
        
        if q.len > 50 and #Connected:
            print("foo")
        
    tick(t):
        #Disconnected:
            if ret < max:
                after 5s:
                    -> Connecting
                    ret++
                    rst

            es: -> Fault
        
        - #Connecting:
            prob 80%:
                -> Connected
                .ret = 0

            es: -> Disconnected
        
        - #Connected:
            proc_q
            prob 5%: -> Disconnected
            
    proc_q:
        while q:
            q.pop(0)
            prob 10%: break


mgr = ConnMgr(max_ret: 3)

# DUMP

* 'use' aliases expressions

* nil evals to false, and comparison/ops with it raise a NilErr

* if preceded by an assignment or placed in a {} block, if-ef-_ chains, match stmt or
  flow return values are assigned.

* flow is an expr if used as one; as a standalone, it is a stmt which modifies the orig
  data. Implicit return for flow stmt as well as func calls without paren are not present;
  nil is returned.


* for rhs, dot is only necessary if ambiguity doesn't exist; scoping rules pending; local
  scope is prioritized. For lhs, writes to fields must use a dot, even for compound assgns.
  for arr[idx] = ... and dict assignments, dot is of course not mandatory...

* '==' for val, 'is' for refs. If used with types (which aren't first class), it checks
  the type.

* En is an ortho enum with 1 ortho field in total. OEn means every field value specified can
  be present simultaneously

* enums can either be defined explicitly or inlined with the decl:

OEn Smth [ ... ]
foo = Smth // default; Smth [ ] is also legal
foo = Smth [ Foo ] // starting value

or

foo = OEn [ ... ]  // same, but the template can't be reused


* For enum cmp rhs MUST have the # char. This is to prevent ambiguity, and de-bloat the EQU
  handler.

* @state means create state = enum to be used easily with # and -> trans

* '_' is reserved; don't use it as fields/identifiers


* you can only omit paren for a 0-arity fn (considering defaults) if it isn't used as a val:

foo:
    bar  // bar is called; nil is returned

foo:
    give bar()  // works; 'give bar' fails as closures are deferred to a later version.


* literal suffix 'f' is supported, even if you could just use a decimal dot at that point. k
  is kilo, m is mega, etc. kb is 1024, mb is ... Decided so since kib and mib seemed quite
  verbose...

* a unary - preceding a # on a new line will be treated as ef #...; use -(#...) if you
  really want to turn a bool to -1/0.


* smartness; if a line ends with =, read the next wrapped around line. If the next line starts
  with => (flow), don't process it as the next line rather as a continuation of the curr.

* (x, y){ } is a lambda. It could even contain stmts. Without () before {}, it just becomes a
  block (yes, could he used with map, sel, sort. Actually map is obsolete now since just {}
  anyways means map) which runs and optionally returns a val (default return for all is nil).
  
  Useful with flow:

a = 1..5 => {
    ...
    rand(1..89..$)  // need to think of syntax for user defined alias for $ (passed curr_val)
}


* need to think about iterators; especially ranges

* need to probe the efficiency of sel vs sparse generation with condition...

* dict literals only allow identifiers as keys and not strings. access/update/creation mandate
  strings though.

* empty dicts are [:]. Need to decide a syntax for sets; Set [] might work, try to make this
  more general and meaningful, especially with SList, DList, Queue, CircQ...

* vars starting with __ can neither be created nor accessed by the user; reserved for internal
  purposes; particularly with our time syntax.
